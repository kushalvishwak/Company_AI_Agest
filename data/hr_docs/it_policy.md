# IT Access Policy

New employees receive a laptop and standard software access on their
first day. Requests for additional software or elevated access must go
through the IT ticketing system and require manager approval.

Company devices must have disk encryption and the standard endpoint
security agent installed before they can connect to internal systems.

Lost or stolen devices must be reported to IT within 24 hours so
credentials tied to that device can be revoked.

Remote access to internal systems requires multi-factor authentication.
Shared accounts are not permitted; every system access is tied to one
named employee so actions can be traced back to a person.
